Interactive Curriculum

6-Step Execution Roadmap

Click through the mandatory 6-stage engineering curriculum sequence.

01. Discovery — Defining "How Might We"

Establish empathy maps, core user personas, and clear problem statements before writing code. Prioritize mobile content flow.

Key Deliverable: User Empathy Map (Says, Thinks, Does, Feels) & functional requirement specification.

02. Wireframe — Mobile-First Grayscale Validation

Construct low-fidelity wireframes in single-column mobile viewports. Validate layout spacing in grayscale to guarantee visual hierarchy.

Key Deliverable: Grayscale wireframe layouts for mobile (<768px>) and desktop (≥1024px).

03. Semantics — HTML5 Structural Landmarks

Build the document backbone using native HTML5 landmark elements (<header>, <nav>, <main>, <article>, <aside>, <footer>). Overuse of generic divs is explicitly banned.

Key Deliverable: W3C-compliant semantic HTML markup structure.

04. CSS Grid & Flexbox — 2025 Palette & Layouts

Apply 2D CSS Grid for macro layout framing and Flexbox for micro-component alignment. Apply Mocha Mousse, Ethereal Blue, and fluid clamp typography.

Key Deliverable: Modular CSS architecture (variables.css, reset.css, macro-grid.css, components.css, responsive.css).

05. Logic — State Management & Interactivity

Develop native ES6 JavaScript logic for mobile drawer toggle, real-time breakpoint window resize observer, roadmap tab switcher, and Grounded Dark mode persistence.

Key Deliverable: Modular JS scripts (nav.js, breakpoint-widget.js, app.js).

06. Audit — Performance & WCAG Accessibility

Execute WCAG 2.1 AA accessibility audit, keyboard focus state verification, LCP/CLS optimization, and multi-device viewport testing.

Key Deliverable: Verified WCAG 2.1 AA compliance & zero framework production score.
