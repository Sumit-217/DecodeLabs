# DecodeLabs Project 1 — Frontend Foundations & Personal Portfolio

> **DecodeLabs Industrial Training Kit (Batch 2026)**  
> **Track:** Full Stack Development — Project 1: Frontend Foundations & Git  
> **Theme:** *"The Skin" — Semantic UI Design, Responsive Layouts & Version Control*

A modern, responsive personal developer portfolio and interactive technical resume engineered with **Semantic HTML5**, **Vanilla CSS3**, and **Vanilla JavaScript**.

---

## 1. Overview & Objectives

Project 1 establishes core competencies in client-side interface design and version control workflows:
* **Semantic HTML5**: Well-structured hierarchy using `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`.
* **Modern CSS3**: Custom properties (CSS variables), Flexbox, Grid, fluid typography, and media query breakpoints.
* **Interactive UI**: Dark/light theme toggling, smooth scrolling navigation, dynamic project filtering, and accessible contact forms.
* **Version Control**: Git repository management, branching, clean commits, and GitHub publishing.

---

## 3. Key Features

* **Hero Section**: High-impact personal introduction with developer call-to-action buttons.
* **Technical Skills Matrix**: Visual badges categorized by Frontend, Backend, Databases, and DevOps tooling.
* **Project Showcase**: Filterable gallery of featured software engineering projects with live demo and repository links.
* **Experience & Education Timeline**: Structured timeline of academic milestones and professional training.
* **Accessible Contact Form**: Form inputs with validation states, focus rings, and responsive submission handling.

---

## 4. Getting Started

Open `index.html` directly in any modern web browser or serve via a local static server:

```bash
# Using Python
python -m http.server 3000

# Using Node (npx)
npx serve .
```

Visit `http://localhost:3000` to view the live portfolio.
